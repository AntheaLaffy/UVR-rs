# 分離を速く、実行環境を小さく

[English](performance-summary.md) | [简体中文](performance-summary.zh-CN.md) | 日本語

UVR Rust は、CPUでの推論速度と小さなネイティブアプリを重視しています。この開発機でのVR処理は **RTF約2、Python参照実装は約6** で、観測された処理速度の差は **約3倍** です。現在のLinux native CLIは **6.94 MB**、デスクトップ実行ファイルは **18.91 MB**。PythonやPyTorchを同梱しません。任意のOpenVINO高速化ライブラリは別途 **86.80 MB**、GUIと合わせて **105.71 MB** です。モデルとOSライブラリは含みません。

## 測定条件

RTFは「処理時間 ÷ 音声の長さ」です。小さいほど高速で、RTF 2なら10秒の音声に約20秒かかります。ライブのリアルタイム処理にはRTF ≤1が必要です。

| 保存された測定 | Rust native | Python参照実装 |
| --- | --- | --- |
| モデル | 5-HP | 5-HP |
| 開発機 | Intel i5-13420H、Linux | 同じ開発機 |
| 音声の長さ | 10秒 | 3秒 |
| CPUスレッド数 | 8 | 2 |
| ウィンドウ／バッチ／並列ウィンドウ | 512 / 1 / 4 | 512 / 1 / 1 |
| ウォーム実行5回のRTF中央値 | 1.9917 | 6.0809 |

入力の長さとスレッド数が異なるため、「約3倍」はこれらの設定で観測された値の比較です。同じリソース条件での比較や、すべてのUVRモデルに対する速度保証ではありません。測定にはPCM解析、推論、再構成を含み、モデルの読み込みとファイルのデコード・エンコードは含みません。Rustの5回の出力は既存の波形誤差基準を満たしています。

[測定値と元データのチェックサム](../benchmarks/2026-09-13-runtime-summary.json)をリポジトリに保存しています。[VRの実験記録](../benchmarks/2026-09-11-vr-cpu-optimization.md)には別途、同じリソース条件で行った過去の測定もあります。

## ファイルサイズの範囲

9月13日のビルドはIntel i5-13420H上でUTC 10:06:28に完了しました。Linux x86_64のrelease最適化、`-C target-cpu=native`、シンボル除去を使い、OpenVINO機能を有効にしています。`target/native/release/build-info.json`に実行ファイルのバイト数、SHA-256、ビルド設定を記録しています。最終ファイルのハッシュを照合し、配置した各ライブラリのサイズとハッシュとともに[追跡対象のデータ](../benchmarks/2026-09-13-runtime-summary.json)へ保存しました。

| 現在のファイル構成 | バイト数 | MB |
| --- | ---: | ---: |
| CLI実行ファイル `uvr` | 6,943,112 | 6.94 |
| デスクトップ実行ファイル `uvr-gui` | 18,905,752 | 18.91 |
| 追加のOpenVINO CPUライブラリ `lib/` | 86,800,978 | 86.80 |
| CLI + OpenVINOライブラリ | 93,744,090 | 93.74 |
| GUI + OpenVINOライブラリ | 105,706,730 | 105.71 |

1 MB = 1,000,000バイトです。追加ライブラリの合計は、コピーした別名ファイルも含めて配置済み10ファイルの長さを合算した値です。圧縮やファイルシステムのブロック単位への丸めは含みません。すべての合計からモデル、OSライブラリ、メタデータファイルを除きます。GUIは推論を内蔵し、CLIを追加する必要はありません。Burn-onlyビルドは`target/native-burn/release/`に出力され、これらのOpenVINOライブラリは不要です。その実行ファイルサイズを今回のOpenVINO対応ビルドから推定することはできません。

9月12日の過去のrelease版も別途記録しています。`uvr`は9,122,024バイト（9.12 MB）、`uvr-gui`は25,811,240バイト（25.81 MB）で、現在の画面とランタイムの更新前の成果物です。サイズの減少はシンボル除去を含む今回のビルドに対応し、上記の保存済み推論時間とは別の記録です。

Burn版はPythonとPyTorchを必要としません。TauriはOSのWebViewを使い、Chromiumを同梱しません。1296用のOpenVINOは任意の追加ランタイムで、そのライブラリは上表に別途記載しています。各モデルの重みと、LinuxのGTK／WebKitシステムライブラリは必要です。

上流UVRのWindows／macOSインストーラーにはPython依存関係が含まれています。本プロジェクトの利点はその実行環境を配布物に持たせないことであり、UVRの全利用者がPythonを手動で設定するという意味ではありません。[上流の説明](../upstream/README.md)も参照してください。

## 再現と改善

`pnpm build:native` でビルドし、[ランタイムガイド](runtime.ja.md)に従って設定します。比較を公開する場合は、音声、重みのチェックサム、プリセット、測定範囲、ハードウェアを揃え、スレッド数とウォーム実行の全結果を記録してください。高速化を採用する条件には波形検証も含みます。

詳細な[性能測定手順](performance.md)と研究記録は現在中国語です。
