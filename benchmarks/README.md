# 基准记录

测量规则见 [性能协议](../docs/performance.md)。这里暂不创建空 benchmark crate；有实际推理接口后再添加执行工具。

## 实验模板

- 实验编号／日期：
- 问题与比较对象：
- Git 提交／是否有未提交变更：
- 构建命令、工具链、特性、锁文件校验和：
- 系统、CPU、GPU、驱动、内存、电源模式、线程数：
- 模型、权重与配置校验和：
- 参考实现版本：
- 输入清单与校验和：
- 推理参数、输出格式和数值精度：
- 执行命令及计时边界：
- 预热次数、测量次数、全部原始样本：
- 冷启动／热运行耗时、RTF、分阶段耗时：
- 峰值 RSS／显存及测量工具：
- 输出长度、增益、误差指标与听评：
- 原始产物位置：
- 结论、适用范围与限制：
