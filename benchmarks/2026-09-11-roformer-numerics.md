# 1296 完整网络与数值定位

日期：2026-09-11。Rust 已实现 1296 的全部频带投影、12 层时间／频率 Transformer、最终 RMSNorm、62 个掩码头和复数掩码重建。699 个原始 checkpoint 张量严格加载通过；CPU FP32 网络、两线程，运行进程设置 `PATH=/nonexistent`。原 FP32 STFT 完整窗口未通过 RMS 门限；统一为工程基线 v1.1 的 float64 正向频谱后，同一个 8 秒输入、短输入和真实片段 CLI 已通过原有门限。跨窗继续验证。

原始网络三组样本为 4096 个普通采样、1025 个最短反射脉冲和 4410 个静音采样，输出分别为 3969、882、4410 个采样。最大绝对误差分别为 `1.1964e-7`、`9.5497e-12`、`0`，全部通过；进度、错误输入与取消也通过。参考清单 SHA-256 为 `01ade5d4c2efead0bcc0394f97d3a7701756d25642d6db093b4cceea3f11e65b`，报告 `benchmarks/artifacts/backend-probe/1296-model.json`。

完整音频调度另通过四组样本：4097 个双声道合成采样、单个单声道采样、7 个 22.05 kHz 采样、503 个 48 kHz 静音采样。输出每轨精确为 4097、1、14、463 个双声道采样，最大绝对误差不超过 `2.0862e-7`，静音跳过网络且严格为零，窗内取消返回正确错误类型。清单 SHA-256 为 `1d770c0f0a3761a7588113d2c5916232814b9973f5c4a98b54f6c5fb15e939c8`，报告 `1296-audio.json`。这些结果未覆盖跨窗和真实片段。

完整 352800 采样窗口逐样本检查通过，但左声道 RMSE 为 `3.019027276e-6`，参考 RMS 为 `1.048514574e-3`，超过原定相对 RMS 门限。合并双声道仍不满足每轨门限，不能归因于探针最初按声道检查得更严格。失败保存为 `1296-full-failure.json` 和 `1296-full.time`；没有生成成功报告。参考清单 SHA-256 为 `11d89db0c4a9082978fc06dd2a979b162b725b6b5ba69a789584a7ad4420178c`。

为隔离误差，将 Rust STFT 输出交给原始 PyTorch 网络，其余权重、网络和 ISTFT 不变。得到左声道 RMSE `3.019011926e-6`，与完整 Rust 的偏差几乎相同；右声道为 `5.5516e-8`。这证明该样本的主要差异来自频谱前处理。直接频谱 RMSE 仅 `5.2556e-7`，但低能量频带经过参考 RMSNorm 后最大频带 RMSE 达 `0.0085192`，说明后续网络放大了前处理舍入差异。诊断产物在 `1296-stft-diagnosis/`；它们不会覆盖黄金数据。

继续对齐原始 PyTorch Hann 系数、使用 FP32 窗乘法与 float64 FFT，原始网络的整轨 RMSE 降至 `1.582478058e-6`，仍超过对应 `7.417215639e-7` 门限。仅在 Rust 中提高 FFT 精度不足以复刻另一套 FP32 FFT 的舍入结果。

因此固定 [工程基线 v1.1](../docs/baseline.md)：两侧统一 float64 Hann、窗乘法与正向 FFT，转 complex64 后执行原始 FP32 网络，ISTFT 使用同一 Hann 窗转 float32。原始黄金输出与失败记录保留，新预设另行生成并按原门限验证，不能称为原 FP32 STFT 的逐样本复刻。三组独立 float64 STFT 样本已通过 Rust 对照（清单 SHA-256 `164a0b5bacfb9954aa26a2ea0a6290971b72fc587a6fccc181244c33c45717ac`）。

修订后同一 8 秒输入的整轨 RMSE 为 `1.767127304e-9`，参考 RMS 为 `7.408473339e-4`，最大绝对误差为 `2.235174179e-7`；逐样本、每轨 RMS、形状、有限值和取消检查全部通过。新旧输入 SHA-256 均为 `ce72ef909fed4ea01f154c259a6aab1db5798e9ff0e67b9729c2d4499256bbe6`，没有更换输入规避失败。新参考清单为 `bfd653a34c489f945811cc6f25e3149735ae3974864afabe3c8b51bb57498494`，报告／实际输出为 `1296-f64-full.json`、`1296-f64-full.0.f32`。探针 SHA-256 `020ee3454df3eaa11204b87446e4e59317db207949bf4269e290c3abb8e58420`；当前正向频谱实现 `17fd53632c411834dde93e4c0f8b9e48a5f400c0a1510c9d15c140511058430e`，网络实现 `5b5e3496c44825be3bd0587dfd58363ed672125c47d47b57fc19074212973a3d`。本次检查期间有编译任务，单次耗时不作性能达标依据。
