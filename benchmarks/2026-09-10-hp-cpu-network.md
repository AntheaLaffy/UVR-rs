# 5-HP／6-HP 完整 CPU 掩码网络

日期：2026-09-10。core 的 `burn-cpu` 原型直接读取两套原始 `.pth`，在 Rust 内完成全部网络前向。两套权重各 459 个张量的名称、形状、类型和浮点有限值全部校验通过；训练专用辅助输出层和 BatchNorm 计数器也校验，没有跳过未知键。文件 SHA-256 必须匹配 [已核验权重](../references/verified-weights.json)。

两套模型各 3 个样本全部通过完整掩码逐元素检查，阈值沿用 `1e-3 + 1e-4 * abs(reference)`。普通输入为确定性幅度谱，另有静音和稀疏脉冲；没有把幅度谱样本当作实际歌曲。

5-HP／6-HP 的模型加载时间分别约 0.639／0.567 秒，包括完整文件摘要、Rust checkpoint 读取、张量校验与后端权重准备；文件系统缓存未控制，因此不标为磁盘冷加载。整个探针进程峰值 RSS 分别为 610112／590532 KiB，包含常驻参考样本和权重；不是单次任务的增量内存。

原型保留未折叠的 BatchNorm、完整阶段拼接与上采样，未做内存规划或专用算子优化。输出复制最高预测频点到 Nyquist，并裁掉左右各 128 帧上下文，和固定上游 `predict_mask` 语义一致。接口拒绝不合要求的窗口长度、错误输入尺寸、NaN 和负幅度；两次探针都执行了这些检查，另验证了未知权重摘要返回失败。
